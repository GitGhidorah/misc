How to explore
Forward process
Drag the slider from 0 → 100. Watch red points scatter away from the green manifold. At t = 100, the original structure is completely lost.
Reverse process
Set t to 80–100, then click Run one reverse step repeatedly. The score function (blue arrows) guides each noisy point back toward the manifold — one probabilistic step at a time.
