Attention and FFN, side by side

Both add information into the residual stream, but what happens inside Attention and inside an FFN is completely different. Every step's heading carries a permanent Attention / FFN badge, and both pipeline diagrams include both an Attention block and an FFN block (one of them just shown as an inactive gray box) — so wherever you scroll, it's always clear which mechanism, and which part of the whole block, you're looking at.

How Does "The Former" Arrive at "Dog"?

We expanded the embedding to 10 dimensions, giving routing dimensions ("item-1-ness" / "item-2-ness") and content dimensions ("dog-ness" / "cat-ness") clearly separate axes. Since the routing dimensions come from a word's position in the sentence rather than the word itself, we also split the context-free static embedding from the positional role that gets added on afterward.

Value, conversely, doesn't carry the "routing" dimensions — only the "content" ones. The Softmax weights blend Dog's and Cat's Value vectors, and the result is added into "the former"'s vector.

07 Attention The story so far

Token embeddings are context-free
The vocabulary-table embedding for the token "dog" is always the same wherever it sits. Position-dependent information like "item-1-ness" doesn't exist yet at this stage.
A shallow layer writes in the positional role
A shallow layer that detects positional encoding and the "A and B" parallel construction additionally writes just the item-1/item-2 dimensions into the residual stream. Only now does it become a "contextualized" vector.
Routing and content are different dimensions
In the resulting final vector, "item-1-ness/item-2-ness" (routing) and "dog-ness/cat-ness" (content) coexist as independent axes.
The Q/K dot product — only looks at the routing dimensions
This Attention head's Q and K reference only the 2 routing dimensions. The dog-ness/cat-ness dimensions contribute nothing at all to the Q·K dot product. "Where to look" is decoupled from "what's written there."
Softmax → weighted sum
The scores computed from the routing dimensions are turned into weights by Softmax, and those weights blend the Value vectors (which carry only the content dimensions).
Adding to the residual stream
The blended Value is added to "the former"'s original vector, not overwritten. As a result, "the former"'s "dog-ness" dimension rises by exactly the Attention weight, and later layers can treat "the former ≈ dog."
(From here, it's the FFN's job)
Deciding which token to look at is Attention's role. What to do with the "dog-ness" that got carried over is handed off to the FFN layer that follows.
A note on simplification: real models don't have neat dedicated axes like these 10 dimensions. Many features are superimposed and typically encoded as "directions" rather than single axes. There are also multiple Attention heads, and the separation between routing and content is usually far less clean than shown here. This visualization isolates just one point: that in principle, "dimensions used for routing" and "dimensions carrying content" are different things.

Toy Transformer Lab — FFN Edition

How Does "What Is the Capital of France?" Arrive at "Paris"?

This time it's FFN, not Attention. Following the view of an FFN as a "key-value memory made of many neurons" (Geva et al., 2020), we've reproduced how each neuron holds a Key that detects a combination of "country" and "topic," fires through ReLU once conditions are met, and writes its corresponding Value (that city's identity) into the residual stream.

02 FFN The full computation pipeline

The input vector x is passed to all 3 neurons. Each neuron independently computes Key·x − threshold, and adds its own Value to the residual, scaled by however much passes through ReLU. Unlike Attention, the neurons don't compete with each other (there's no softmax). The gray box at the top just marks where the earlier Attention layer that built this input x sits — nothing is computed there in this demo.

03 FFN Zooming in on the firing

Just the "Key·x → ReLU" part of the diagram above, pulled out. Three arrows extend from the input x; their thickness and opacity show each neuron's firing strength.

04a FFN Static token embeddings (from the vocabulary table)

The embeddings for the tokens "France" and "capital", separately. At this stage they haven't yet been combined into a single position. Choosing a different country doesn't change the shape of the words' own embeddings.

04b FFN Aggregation by an earlier Attention layer (shallow layer)

An FFN can only see the vector at one position. So an earlier Attention layer copies both the "France" and "capital" tokens' features into this position ahead of time. It's the same idea as "a shallow layer writes in the positional role" from the dog/cat example.

04c FFN The final vector passed to the deeper (FFN) layer (= 04a + 04b)

The result of aggregating both tokens' features into a single position. The content (city-ness) dimensions are still all zero — from here on we move into the "Key/Value" computation from the pipeline diagram.

05 FFN The dimensions Key actually reads

Each neuron's Key only looks at 2 of the 10 dimensions — "country" and "topic." The grayed-out rows have values, but this neuron ignores them entirely.

06 FFN The weighted sum of Value, and adding it to the residual stream

Key only looks at the "country/topic" dimensions, but Value, conversely, doesn't carry those — it only carries the "city-ness" dimensions. Value, weighted by the firing strength that passed through ReLU, gets added into the input vector.

07 FFN How this differs from Attention

No competition
Attention's weights are normalized by Softmax, so multiple candidates fight over the weight. FFN neurons just pass independently through ReLU, so as long as conditions are met, multiple neurons are free to fire at once.
ReLU creates an AND condition
Because it only fires once Key·x crosses the threshold, "the country matches" alone or "the topic matches" alone isn't enough — it only fires once both are satisfied. This AND-like behavior comes purely from a thresholded linear sum plus ReLU.
"Knowledge" sits statically inside the neurons
Attention dynamically references other tokens in the sentence, whereas an FFN's Key-Value pairs are fixed at training time and always return the same Value for the same input pattern from then on — functioning as a static store of knowledge, like an encyclopedia index.
A note on simplification: a real FFN layer has thousands to tens of thousands of neurons, and a single fact is often stored in a distributed way, superimposed across multiple neurons — it's rarely the case that one single neuron cleanly "handles Paris." The real threshold is also learned as a bias term, and Key vectors operate on representations transformed by earlier layers rather than raw embeddings. This isolates just the central mechanism: "Key·x − threshold → ReLU → weighted sum."
