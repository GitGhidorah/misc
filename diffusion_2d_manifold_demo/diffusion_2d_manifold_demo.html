Score smoothing on a 2D data manifold

A real 2-layer score network is trained with denoising score matching on 8 training points placed on a ring (a toy 2D data manifold), then used to actually run reverse diffusion sampling. Adjust the weight decay (regularization strength) to see the tradeoff between memorization and interpolation — and how the effect is direction-dependent relative to the manifold.

Try 0 first (memorization), then move right to see interpolation, then further right for over-smoothing.
